# 保護者のみなさまへ｜おうちでの「今日の10分」

英語の音と文字に、おうちでも少しずつふれるための学習ページです。

**開き方**　先生から届いたリンクを開く →「今日の10分」の3つを上から順に「はじめる」

**ペース**　1回 約10分、週3回がめやすです。毎日でなくて大丈夫です。3つ終わったら、その日はおしまいです。

**お願い**
- 音が出ます。はじめての回は、音が聞こえているか一緒に確認してください。
- 毎回、同じ端末で開いてください（進み具合のしるしは端末の中に保存されます）。
- ニックネームを入れる場面では、本名ではなくニックネームを使ってください。

**声かけのヒント**
- 「何点だった？」より「今日はどの音をやったの？」「その音、聞かせて」
- まちがえても大丈夫です。もう一度出てきます。

**10分で終わらないとき**　2つまでで終わりにして、残りは次の回に。

お困りのときは、担当の先生までご連絡ください。
