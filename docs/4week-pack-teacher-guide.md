# はじめての英語 4週間パック｜先生用ガイド

対象：英語を習いはじめた小学生（年長〜小4くらい）
ペース：1回 約10分 × 週3回 × 4週間（全12回）
生徒に配るリンク：`https://wise-english-portal.vercel.app/course/hajimete`

## 配り方

1. 初回の授業で、上のリンクを保護者に送る（LINE・メール・QRコードなど）。
2. 生徒はリンクを開き、「今日の10分」に出ている3つを上から順に「はじめる」。
3. 3つ終わったらその日はおしまい。次に開くと、つづきの回が出る。

会員登録は不要。✓ のしるしは端末の中だけに保存されるので、毎回同じ端末で開いてもらう。

## 4週間の内容と、授業での口頭確認

| 週 | 家庭学習の内容 | 次の授業での確認（2〜3分） |
|---|---|---|
| 1 | s a t i p n の音を聞く・聞き分ける・文字と合わせる。sat / pin など短い単語 | 文字カードを見せて音を言う。sat, pin, tap を音からつないで読む |
| 2 | ck e h r m d の音。cat / hen / red など | 先生が音を言い、生徒が文字を指す。hat, red, men を読む |
| 3 | g o u l f b の音。dog / bug / leg など | 絵を見せて最初の音を言う。dog, bus, leg を読む |
| 4 | 写真と音声で単語12語。Am / Is / Are。ことばを並べて短い文 | 覚えた単語を1つ使って I like ___. を言う |

## 各回の3ステップ

- **おぼえる**：音や単語にはじめてふれる（時間制限なし）
- **たしかめる**：習った内容だけの短いクイズ（5〜10問）
- **つかう／ふくしゅう**：ゲームで使う、前の週の内容にもう一度ふれる

配信表（各回のゲームと分数）は `https://wise-english-portal.vercel.app/teachers` に載っている。印刷して使える。

## よくあるつまずき

- **音が出ない**：端末のマナーモード・音量を確認。音声は端末の読み上げ機能を使うため、端末によって聞こえ方が違う。
- **10分で終わらない**：3つのうち2つまででよい。残りは次回に回す。
- **簡単すぎる**：学習ホームの「英検5級の単語 30語」コースへ。

- 含まないもの：生徒ごとの添削、毎日の進捗確認の代行
